How to use the timetable generator

1

Save the report as a CSV

  • Open the Scheduling Summary Report (.xlsx).
  • Choose File > Save As and pick CSV UTF-8 (Comma delimited) (*.csv).
2

Load it

Drop the CSV on Load data, or click it to browse. The file stays on your computer.

3

Choose courses

Search by course code or CRN, or add a program year from Add a program year. Codes have no spaces and end in the campus letter: MATH1010U.

4

Read the week

Classes shows every section as a block. Density shades each time slot by how many courses meet then, so quiet times stand out.

5

Find workshop times

In Workshop scheduler, tick the courses to avoid most, set the length and time window, then choose Find workshop times. Lower scores mean fewer clashes; hover a result to see why.

How scores add up

  • +1 Tutorial or lab
  • +5 Lecture
  • +3 Avoid-most tutorial or lab
  • +20 Avoid-most lecture

Each overlapping section counts once. Two tutorials and one avoid-most lecture score 1 + 1 + 20 = 22. Defaults shown; change them in Advanced settings.
